# Security Policy

## Scope

This repository publishes offensive-security proof-of-concept code (.NET memory shells) for
**authorized penetration testing and defensive research**.

## Responsible Use

- Only test systems you own or have **written authorization** to test.
- The techniques assume an already-compromised host (a known/leaked `machineKey` or another
  .NET deserialization vector). They are post-exploitation research artifacts, not exploits.

## Reporting

For issues with the code itself, open a GitHub issue. Do **not** open issues requesting help
attacking specific targets — they will be closed.
